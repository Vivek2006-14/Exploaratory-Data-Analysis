# Task 5 - Exploratory Data Analysis (EDA)

## Objective
The objective of this task is to perform Exploratory Data Analysis (EDA) on the Titanic dataset and extract useful insights using visual and statistical exploration.

## Dataset
Titanic Dataset

## Tools and Libraries Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
- Dataset overview using `info()`
- Statistical analysis using `describe()`
- Missing value analysis
- Categorical value analysis using `value_counts()`
- Age distribution histogram
- Fare distribution boxplot
- Age vs Fare scatterplot
- Survival by gender analysis
- Correlation heatmap
- Pairplot

## Key Findings
1. The Titanic dataset contains information about passengers including age, gender, passenger class, fare, and survival.
2. The age distribution shows that many passengers were relatively young.
3. Fare values contain some high-value outliers.
4. Female passengers had a higher survival rate than male passengers.
5. Passenger class and fare show noticeable relationships with survival.
6. The visualizations helped identify patterns, relationships, and possible anomalies in the dataset.
